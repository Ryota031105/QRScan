## ページ構成

### QRスキャンページ

#### 概要

- カメラを起動し、QRコードをスキャンする
- スキャンしたデータがDBに存在するとき
  - ダイアログが表示される（OKボタンを押すとダイアログが消え、処理が継続）

  ```
  下記の物品情報を更新します。

  所在地：A
  物品名：パソコン
  ```

  - 該当のレコードの`update_at`を現在の日時(`yyyy/mm/dd hh:mm:ss`)に更新
  - 該当のレコードの`checked`を`true`に更新

- スキャンしたデータがDBに存在しないとき
  - ダイアログが表示される（OKボタンを押すとダイアログが消える）

  ```
  下記の物品は未登録です。
  新規登録します。

  所在地：A
  品名：パソコン
  ```

  - 以下の設定でレコードを登録
    - `id`：主キーであるため自動設定
    - `location`：読み取ったJSONデータの`location`
    - `item_name`：読み取ったJSONデータの`item_name`
    - `update_date`：スキャンした日時(`yyyy/mm/dd hh:mm:ss`)
    - `checked`：`true`

#### コンポーネント

- カメラコンポーネント
- ダイアログ

### DB確認ページ

#### 概要

- DBテーブルがWEB上で確認できる
- DBテーブルをCSVでダウンロードできる
- カラム`checked`の状態を変更できる（一括変更可）
